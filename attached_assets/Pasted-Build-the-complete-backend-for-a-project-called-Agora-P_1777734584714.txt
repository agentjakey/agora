Build the complete backend for a project called Agora.

PROJECT PURPOSE:
Agora is a multiplayer philosophical "Would You Rather" app. Users join rooms
with a short room code. Each room gets AI-generated philosophical dilemmas —
designed to be thought-provoking and debate-starting. Users vote in real time.
Results appear as a live split bar. The experience is designed to feel like
a Socratic dialogue, not a trivia game.

TECH STACK:
- Backend: Python FastAPI
- Frontend: React (build later, in /frontend)
- Real-time: FastAPI WebSockets (built-in, no external broker needed)
- LLM: Anthropic claude-haiku-3-5-20241022 via the anthropic Python SDK
- Storage: In-memory Python dicts (no database — rooms expire on server restart)
- Secrets: ANTHROPIC_API_KEY from environment

DATA STRUCTURES:
In memory, maintain:

rooms = {}  # room_code -> Room object

Room object:
{
  "room_code": str,          # 4-letter code, e.g. "AGORA"
  "host_id": str,            # UUID of the user who created the room
  "flavors": list[str],      # philosophical flavors the host selected
  "users": dict,             # user_id -> {"name": str, "connected": bool}
  "current_question": dict,  # see Question structure below
  "votes": dict,             # user_id -> "A" or "B"
  "question_history": list,  # list of past Question objects with vote results
  "phase": str,              # "lobby" | "question" | "reveal" | "ended"
  "connections": list        # active WebSocket connections (not serialized)
}

Question object (generated by Claude):
{
  "id": str,                 # UUID
  "option_a": str,           # full text of option A
  "option_b": str,           # full text of option B
  "framing": str,            # one sentence: what's philosophically at stake
  "flavors": list[str]       # which flavor tags apply to this question
}

ROOM CODE GENERATION:
4 uppercase letters, random, exclude vowels to avoid accidental words.
Consonants only from: B C D F G H J K L M N P Q R S T V W X Y Z

USER ID:
Each user gets a UUID on first connection, stored in localStorage on frontend.
Backend receives it on WebSocket connect.

API ENDPOINTS (REST):

POST /room/create
  Body: { "host_name": str, "flavors": list[str] }
  Creates a new room. Returns: { "room_code": str, "host_id": str, "user_id": str }

POST /room/join
  Body: { "room_code": str, "user_name": str, "user_id": str (optional) }
  Adds user to room. Returns: { "room_code": str, "user_id": str, "room_state": Room }
  Errors: 404 if room not found.

GET /room/{room_code}
  Returns current room state (without WebSocket connections field).

POST /room/{room_code}/start
  Host only. Triggers question generation and moves room from lobby to question phase.
  Body: { "host_id": str }

POST /room/{room_code}/vote
  Body: { "user_id": str, "vote": "A" | "B" }
  Records vote. If all users have voted, broadcast reveal immediately.

POST /room/{room_code}/next
  Host only. Generates next question and resets votes.
  Body: { "host_id": str }

POST /room/{room_code}/end
  Host only. Ends the session.

WEBSOCKET ENDPOINT:

WS /ws/{room_code}/{user_id}
  On connect: add user to connections list. Broadcast updated user list to all.
  On disconnect: mark user disconnected. Broadcast updated user list.
  
  Broadcast events (JSON, server → all clients in room):
  
  { "event": "user_joined", "user": { "id": str, "name": str } }
  { "event": "user_left", "user_id": str }
  { "event": "question_ready", "question": Question }
  { "event": "vote_update", "votes": { "A": int, "B": int, "total": int, "voted_ids": list } }
  { "event": "reveal", "final_votes": { "A": int, "B": int }, "question": Question }
  { "event": "session_ended" }

QUESTION GENERATION FUNCTION:
An async function generate_question(flavors: list[str]) -> Question

Calls Claude Haiku with this system prompt (exact):
"You are a philosophical dilemma designer in the tradition of Socratic dialogue.
Your role is to generate a single 'Would You Rather' question that:
- Presents two genuinely asymmetric options — both have real costs and real rewards
- Touches on philosophical themes: identity, consciousness, knowledge, justice, time, power, or meaning
- Is designed to split a group of thoughtful people and generate real disagreement
- Contains no shock value, no graphic content, no political figures, no trauma triggers
- Is specific enough to picture but universal enough to apply to any human life
- Is appropriate for all ages above 16

Respond ONLY with a JSON object, no markdown, no backticks, no preamble:
{
  \"option_a\": \"full text of the first choice\",
  \"option_b\": \"full text of the second choice\",
  \"framing\": \"one sentence describing what is philosophically at stake between these two options\",
  \"flavors\": [list of 1-3 flavor tags that apply: Consciousness, Identity, Knowledge, Morality, Power, Time, Meaning]
}"

If flavors were selected by the host, include them in the user message:
"Generate a question emphasizing these philosophical flavors: [flavor list]"

Parse the response. If JSON is malformed, retry once. Return the Question object.

ERROR HANDLING:
- All endpoints return { "error": str } with appropriate HTTP status on failure
- WebSocket errors: log and close connection gracefully
- Claude API errors: return a fallback question from a hardcoded list of 10 pre-written questions

Write 10 high-quality philosophical dilemmas in the Question format.
